# Roadmap

Implemented local tooling validates repository metadata, maintained source and licences, workflows, development dependencies, documentation and inventory through fixed commands. It does not compose or assess an assurance argument.

The planned Python library separates argument graphs, actual evidence bindings, gaps, review, export and command handling. Its declared notation subset requires the actual authoritative source before any conformance admission. It is not an implementation of a complete standard or metamodel.

Future graph checks require unique typed nodes, existing endpoints, allowed relations and acyclic support. Context and assumptions cannot replace evidence. The complete declared goal and solution population determines coverage; missing, invalid, irrelevant or unsupported bindings remain OPEN. Structural BOUND never means that a claim is true, sufficient or safe.

Every view and export must preserve scope, OPEN claims, assumptions, unsupported notation, counterevidence, evidence origin and limits. Scope-specific non-certification prose is mandatory. A rendered graph or intact reference does not qualify the evidence or its relevance.

Immutable content precedes actual detached human review; later export binds both under accepted custody and current trust. Adding a review receipt does not alter the reviewed content. Changing any content, scope or evidence binding changes its identity and invalidates old sign-off. The tool cannot invent a reviewer, role, approval or signing authority.

The intended public operations are compose, check, sign, export and verify. They are not installed here. Sign consumes an actual authorized human statement for the exact content and scope; it does not generate approval. Offline verification and Studio must retain the same limitations and review separation.

Completion requires all owned fields and original cases, actual source-qualified producer artifacts and separate consumers, authoritative notation binding, independent graph and review counterexamples, strict native checks, meaningful coverage, documentation and fresh comparison benchmarks. Input evidence keeps its actual maturity. No safety, regulatory or certification determination is provided by this tooling.

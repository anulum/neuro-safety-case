# Repository boundary

Status: accepted for local tooling construction.

NEURO-SAFETY-CASE owns repository validators now. Its planned Python library composes a typed, scoped argument from actual upstream evidence and exposes gaps, limits and separate human review. It does not generate instrument evidence, confer maturity on inputs or issue an automated approval.

Common representation and custody stay Toolkit-owned; evidence owners retain their own source, method and physical qualification, Ledger retains lineage, and assessors retain judgments of relevance and sufficiency. A declared notation subset is separate from verified standard conformance.

Immutable content has no own or future review/export reference. A detached human statement binds exact content, scope, reviewer and role; a later export binds both. Changed content needs a new actual review. Context and assumptions cannot close an unsupported claim or inflate coverage.

The planned pack identifier is separate from registered or qualified formats. Future changes must add genuine public producers and separate consumers, full original cases, strict checks, tests, docs and affected benchmark parity in the same complete change. Owner wording and domain review remain conditions of any later certification-relevance publication.
